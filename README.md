# DZ HOOF

منصة IPTV قانونية لإدارة وتشغيل المصادر التي يملك المشغل حق استخدامها.

## مكونات المشروع

- `server/`: Backend API ولوحة تحكم Admin (Express/MongoDB/Redis + Next.js).
- `android/`: تطبيق Android وAndroid TV (Kotlin/Compose، Media3/ExoPlayer).
- `PROJECT_ROADMAP.md`: الخطة الحالية، النطاق، المراحل، وقواعد GitHub.
- `AGENTS.md`: قواعد العمل التي يجب اتباعها عند تعديل المشروع.
- `RECOMMENDED_PROJECTS.md`: المشاريع الخارجية التي تمت مراجعتها وما يمكن الاستفادة منه منها.
- `docs/`: تقارير فحص وتشغيل ونشر (عربية/إنجليزية).
- `scripts/setup-demo-sources.mjs`: استيراد مصادر العرض تلقائيًا من متغيرات البيئة.

## الحالة الحالية (2026-08-18)

- **Backend**: 200/200 اختبار خضراء (27 مجموعة، تغطية ≥70%) + lint + typecheck في البناء المحلي.
- **لوحة الإدارة**: تشغيل مباشر (preview) للقنوات والأفلام والمسلسلات عبر **توكنات مشفرة** دون كشف روابط المصدر؛ اختيار جودة البث، صورة داخل صورة، ومفاتيح اختصار للمشغل.
- **أمان البث**: توكنات AES-256-GCM قصيرة العمر + بروكسي يعيد كتابة HLS + حماية SSRF + إعادة تحقق من الاشتراك عند كل تشغيل.
- **استيراد Xtream/M3U** مع معاينة وrollback؛ الحلقات (Seasons/Episodes) تُجلب **عند الطلب** (lazy) بدل مزامنة تستغرق ساعات.
- **البث من هذا الساندبوكس/بيئة الاختبار**: قنوات iptv-org الحرة تعمل فورًا؛ مصادر البانلات التجارية قد تحجب IPs الداتاسنتر (456) — تُفعّل تلقائيًا عند النشر على VPS بمعرف IP غير محجوب (انظر `docs/DZHOOF_RUNTIME_REPORT_2026-08-17_AR.md`).

## قبل الاستخدام

1. استخدم مصادر IPTV قانونية ومصرحًا بها فقط.
2. انسخ `server/.env.example` إلى `server/.env` واضبط القيم المحلية (أنشئ أسرار JWT عشوائية).
3. ضع عنوان HTTPS الحقيقي للخادم في إعداد Android بدل `https://dzhoof.example/`.
4. شغّل الخادم مع MongoDB وRedis، ثم اختبر تسجيل الدخول واستيراد M3U والاقتران.
5. لإعادة بناء بيئة العرض بسرعة: `node scripts/setup-demo-sources.mjs` (راجع `docs/DEMO_ENV_SETUP_AR.md`).
6. راجع `PROJECT_ROADMAP.md` قبل إضافة ميزات جديدة.

## خطة التطوير المختصرة

1. تفعيل CI على GitHub (Workflows) عند توفر الصلاحية.
2. النشر على VPS حقيقي + نطاق + HTTPS + نسخ احتياطي مجدول.
3. بناء APK Release موقّع واختباره على أجهزة TV حقيقية.
4. إصلاحات P1 الأمنية: Redis rate limiting، device tokens، FCM، Play Integrity.
5. الدفع الإلكتروني ولوحة Reseller عند اكتمال المنتج.
