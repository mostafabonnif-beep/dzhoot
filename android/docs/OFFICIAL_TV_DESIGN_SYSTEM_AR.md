# DZ HOOF TV — نظام التصميم للإصدار الرسمي

## هدف النسخة

تطبيق **DZ HOOF TV** هو واجهة تلفاز مخصصة للمصادر المرخّصة التي يديرها المستخدم. يجب أن يشعر المستخدم أن التطبيق سريع وواضح ويمكن التحكم به كاملاً بالـD-pad من مسافة مشاهدة التلفاز.

> هذا المستند يوجّه النسخة التجريبية الرسمية. لا يغيّر سياسة المحتوى: لا تُعرض أو تُستورد إلا مصادر يملك المشغّل حق استخدامها.

## هوية المنتج

| العنصر | القرار |
|---|---|
| الاسم الظاهر | **DZ HOOF TV** |
| الأسلوب | داكن أولاً، هادئ، مناسب لشاشة 10-foot UI |
| اللون الأساسي | Flame Amber `#F7A93A` |
| الخلفية | Void `#0A0A12` |
| سطح البطاقات | Void `#191921` |
| لون النجاح | أخضر واضح للحالة المتاحة فقط |
| تركيز التلفاز | حد Flame Amber مع glow خفيف؛ لا يعتمد على اللون وحده |

## مسار المستخدم الأساسي

1. **التشغيل الأول:** شاشة هوية قصيرة ثم ربط آمن بالـPIN أو QR، دون ظهور خيارات مصدر متقدمة قبل اختيار "مصدر آخر".
2. **الرئيسية:** زر "شاهد الآن" هو موضع التركيز الأول، يليه الصف المميز ثم "شاهدتها مؤخراً" والفئات.
3. **المشاهدة:** تحكم D-pad ظاهر، معلومات القناة عند الطلب، وإجراء سريع للمفضلة والتبديل المتعدد.
4. **البحث والدليل:** الوصول إليهما من شريط التنقل؛ النتائج تقسم إلى مباشر وأفلام ومسلسلات وبرامج.
5. **الإدارة:** الاشتراك، الأجهزة، الرقابة الأبوية، والإعدادات داخل قسم واضح لا يقطع تجربة المشاهدة.

## قواعد التلفاز

| الموضوع | معيار التنفيذ |
|---|---|
| التركيز | كل عنصر قابل للنقر يجب أن يملك حالة focus مرئية ومرتبطة بالاتجاهات بشكل منطقي. |
| النص | لا يقل النص الأساسي في واجهة TV عن حجم مقروء من 2.5–3 م تقريباً؛ تمنع العناوين من القطع غير المقصود. |
| الحركة | انتقالات قصيرة مع احترام خيار تقليل الحركة. |
| التحميل | Skeleton مطابق للصفحة، ورسالة خطأ تقدم إعادة المحاولة أو الربط عند غياب المصدر. |
| الحالة | لا تعرض "متاح" إلا عند وجود بيانات صحة موثوقة؛ تفرق بين غير متاح وقيد الفحص. |
| اللغة | العربية RTL أساسية، مع عدم كسر العناوين أو الرموز الإنجليزية والاختصارات. |

## إعدادات الإصدار

| النوع | اسم الحزمة | الغرض |
|---|---|---|
| `staging` | `com.dzhoof.iptv.staging` | اختبار APK على خادم/نطاق تجريبي فقط. |
| `release` | `com.dzhoof.iptv` | إصدار رسمي موقّع بعد نجاح staging. |

يلزم تمرير `-PdzhoofApiUrl=https://...` عند البناء. يجب أن يكون العنوان HTTPS ولا يجوز تضمين بيانات اعتماد أو مفاتيح داخل APK أو Git.

## قبول النسخة التجريبية

قبل اعتماد APK للتجربة، يجب أن ينجح: البناء، تثبيت نسخة staging، الربط، تسجيل الدخول، الرئيسية، تشغيل مصدر مرخص، التنقل بالريموت، البحث، المفضلة، الدليل، الإعدادات، وإلغاء الربط. لا ينتقل التطبيق إلى إصدار رسمي موقّع قبل نجاح هذه القائمة على جهاز Android TV فعلي.
