# بريف حساب Backend (الحساب 3)

**دورك:** تحصين الخادم وإصلاحات P1 الأمنية وتحسينات الأداء.

## مهامك بالترتيب (تقرير الخبير 17/08 + خارطة الطريق)
1. **Redis rate limiting**: نقل الـ rate limit من الذاكرة (per-process) إلى Redis store — مهم مع تعدد النسخ. (`express-rate-limit` + Redis موجود أصلًا)
2. **ترقية channelListCode**: من 6 خانات إلى Device Access Token ≥ 32 بايت عشوائي مخزّن hash مع تدوير/إلغاء، أو رفع الطول لـ 12+ وإيقاف كشف `/verify/:code`.
3. **FCM كامل**: معالجة `onMessageReceived` + تشفير التوكن (بالتنسيق مع حساب Android).
4. **استيراد المسلسلات lazy**: جلب الحلقات عند الطلب بدل الجلب الكامل البطيء (16,698 مسلسل).
5. **Playback API E2E tests**: اختبارات supertest صريحة لمسارات البث (playback-token / authorize / proxy لكل حالات الاشتراك).
6. **حماية PIN**: تشفير bcrypt/scrypt + حد محاولات للمستخدمين (يخص الـ parental PIN).

## قواعدك
- كل تغيير → build + typecheck + lint + اختبارات خضراء (حاليًا 200 اختبار / تغطية ≥70%).
- تحديث توثيق API عند تغيير endpoint.
- لا تكسر: بوابة الاشتراك الموحدة، بروتوكول البث الآمن، SSRF.
