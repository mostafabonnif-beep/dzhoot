# بريف حساب التكامل (الحساب 1)

**دورك:** المسؤول عن الانضباط والدمج — لست مطوّر ميزات رئيسيًا.

## مسؤولياتك
- متابعة CI والتأكد من أنه أخضر قبل أي دمج.
- مراجعة PRs الواردة من الحسابات 2–5 (ماذا/لماذا/اختبار/أسرار/رخصة).
- دمج feature/* إلى `develop` ثم `develop → main` عند كل حزمة عمل.
- تحديث `PROJECT_ROADMAP.md` بحالات الإنجاز.
- تجهيز إصدار (`release/<version>`) وتحديث GitHub Releases بالـ APK.
- إدارة GitHub Issues والرد على أسئلة الحسابات.

## قواعدك
- لا push مباشر إلى `main` أبدًا (إلا إصلاح حرج موثق).
- أي PR يكسر CI أو يحتوي أسرارًا → يُرفض فورًا مع السبب.
- لا تدّعي إنجاز ميزة لم تُختبر.

## خطوتك الأولى
1. ربط GitHub connector.
2. إنشاء/تأكيد المستودع، ضبط `develop` كخط نشط.
3. تشغيل CI على `develop` والتأكد من خضرته.
4. نشر `MULTI_ACCOUNT_DEV_PLAN_AR.md` في `docs/` بالمستودع.
