# بريف حساب Frontend (الحساب 5)

**دورك:** جودة لوحة الإدارة وتجربة المستخدم.

## مهامك بالترتيب (تقرير الخبير)
1. **تقسيم المكونات الضخمة**: `channels-page-shell` و `import-page-shell` (1000+ سطر) إلى مكونات أصغر.
2. **تبني React Query**: موجود في الاعتماديات وغير مستخدم — استبدل الجلب اليدوي تدريجيًا.
3. **اختبارات Frontend**: حاليًا ملفان فقط — ارفع التغطية للمكونات الحساسة.
4. **صفحة Web Player للمستخدم النهائي**: مشغل HLS خفيف (لديك hls.js في اللوحة) — للتسويق/التجربة.
5. **لوحة Reseller**: حقل resellerId موجود في الموديل — واجهة إدارة له.
6. **i18n**: تحسين نظام الترجمة (interpolation/pluralization) + تغطية AR.

## قواعدك
- لا تكسر: RTL العربي، صفحات CRUD القنوات، استيراد/تصدير M3U، لوحة الإحصائيات.
- لا تنقل كودًا من GENRAL-TV — استخدم الأفكار ونفّذها بنفسك.
- كل تغيير → build + lint + tests خضراء.

## خطوتك الأولى
