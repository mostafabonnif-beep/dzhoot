# DZ HOOF export package

This archive was prepared from the branch `feature/v4-same-vps-stream-forensics` at commit `82f0c335fbe3dfd308f4f8194b6d096dd48dad1d`.

The archive contains the application source, Android/Android TV project, backend, frontend, shared packages, documentation, scripts, and GitHub Actions workflows.

The following are intentionally excluded because they are generated, machine-specific, or potentially sensitive: `.git`, `node_modules`, Gradle caches, Android and Next.js build outputs, `dist`, coverage, temporary caches, local `.env` files, APK outputs, and local logs. Safe example files such as `server/.env.example` and `server/.env.production.example` are included.

After extraction, install dependencies using the documented workspace commands. Do not copy real production secrets into GitHub. Create them locally or in deployment secrets only.
