# API — مباريات اليوم (Matches Today)

> الميزة C1 من بنك الأفكار (`IDEAS_2026-08-25_AR.md`): كاروسيل «مباريات اليوم» —
> المباريات الرياضية الجارية والقادمة اليوم على قنوات المشترك.
> تاريخ الإضافة: 2026-09-08 (PR — ميزة الجزء 11).

## الغرض

نقطة نهاية خفيفة ومخزّنة مؤقتًا تعيد مباريات اليوم (جارية + قادمة) من دليل EPG
للقنوات المرتبطة بكود قائمة المشترك، بنفس نطاق الرؤية والصلاحيات المستخدم في
`GET /api/v1/tv/epg/:code` — أي أن المشترك يرى المباريات على قنواته فقط، ولا
يُكشف أي رابط بث أو بيانات اعتماد.

## العقد

### `GET /api/v1/tv/epg/:code/matches-today`

| العنصر | القيمة |
|---|---|
| المصادقة | لا شيء إضافي — `:code` هو كود القائمة (6 أحرف، مثل بقية مسارات `/tv/epg`) |
| النافذة الزمنية | يوم UTC الحالي `[00:00, 00:00)` — قابلة للتطوير لاحقًا لمنطقة زمنية |
| التخزين المؤقت | `epgCache` بمفتاح `matches-today:<code>:<yyyy-mm-dd>` لمدة 120 ثانية + `Cache-Control: public, max-age=120` |
| الحدود | `MATCHES_TODAY_SCAN_LIMIT` (افتراضي 6000، سقف 20000) لمسح اليوم، `MATCHES_TODAY_MAX` (افتراضي 80، سقف 300) لعدد النتائج |

**الاستجابة الناجحة `200`:**

```json
{
  "success": true,
  "date": "2026-09-08",
  "count": 3,
  "matches": [
    {
      "startTime": "2026-09-08T19:00:00.000Z",
      "endTime": "2026-09-08T21:00:00.000Z",
      "status": "live",
      "title": "الجزائر - المغرب",
      "description": "نهائي كأس الأمم",
      "category": ["Sport"],
      "language": "ar",
      "channel": {
        "epgId": "beinsports1.tr",
        "channelId": "c1a2b3",
        "name": "beIN Sports 1",
        "icon": "https://iptv.ld-11.net/api/v1/tv/logo?url=…"
      }
    }
  ]
}
```

- `status`: `live` (بدأت ولم تنتهِ) أو `upcoming` (ستبدأ لاحقًا اليوم). المباريات المنتهية مستبعدة.
- `channel.icon` يمر دائمًا عبر بروكسي الشعارات (`/api/v1/tv/logo`) — لا تُكشف
  أسماء مضيفي صور المزوّدين للمشتركين.
- أخطاء: `400` كود غير صالح، `404` كود غير معروف/معطّل/ملغى، `500` فشل داخلي.

## كيف يُكتشف أن البرنامج "مباراة رياضية"؟

المنطق في `server/backend/src/utils/sports-matches.ts` (دوال نقية — قابلة للاختبار):

1. **فئة البرنامج** (`category`) تحتوي تلميحًا رياضيًا: `sport`, `football`,
   `soccer`, `tennis`, `basketball`, `handball`, `boxing`, `motorsport`, `olympic`…
2. **عنوان البرنامج** يحتوي كلمات مفتاحية:
   - عربية: مباراة، كأس، دوري، نهائي، تصفيات، ودية، الجولة، لقاء، البطولة، ديربي،
     كلاسيكو، ذهاب/إياب، ركلات الترجيح، المونديال، أولمبياد…
   - لاتينية/فرنسية: `champions league`, `premier league`, `world cup`,
     `grand prix`, `derby`, `final`, `cup`, `league`, `vs` (بشروط وجود اسمين حولها)…
3. الوصف لا يُستخدم في التصفية (تقليل الضوضاء).

## الاستخدام في الواجهات

- **ويب**: صفحة `/watch` تعرض شريط «⚽ مباريات اليوم» بعد إدخال الكود؛ النقر على
  بطاقة مباراة يفتح مشغّل القناة مباشرة. (هذا الـ PR)
- **Android / Android TV**: يمكن ربط نفس الـ endpoint لاحقًا لصف «مباريات اليوم»
  في الشاشة الرئيسية — بلا أي تغيير خلفي إضافي.
