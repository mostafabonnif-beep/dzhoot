# سجل حقوق المحتوى وإعادة التوزيع — DZ HOOF

**الحالة:** نموذج تشغيلي يجب أن يملأ من العقود والأدلة الأصلية قبل العرض التجاري العام.
**المالك:** مسؤول الامتثال أو المدير المخول.
**قاعدة الخصوصية:** لا يوضع رابط بث خام أو اسم مستخدم أو كلمة مرور مورد أو نسخة عقد حساسة داخل Git أو ملفات التطبيق. تحفظ الأدلة في مخزن وثائق محمي وتربط بالمعرف الداخلي فقط.

> هذا السجل لا يمنح حقاً قانونياً بحد ذاته. هو دليل تشغيلي يربط كل مصدر بالمستند الذي يثبت نطاق استخدامه. ينبغي مراجعة العقد من محامٍ مختص قبل الاعتماد عليه في البيع أو إعادة التوزيع.

## سجل المصادر والحقوق

ينشأ صف مستقل لكل مصدر أو عقد أو تجديد. إذا اختلف الإقليم أو نوع المحتوى أو حق إعادة البيع، ينشأ صف جديد بدلاً من دمج الحقوق المختلفة في صف واحد.

| معرف داخلي | مرجع العقد أو الترخيص | مالك الحق أو الجهة المتعاقدة | نطاق المحتوى | الأقاليم المسموح بها | طريقة التوزيع المسموحة | إعادة البيع للمشتركين | حد المستخدمين أو المشاهدات | بداية الصلاحية | نهاية الصلاحية | حالة التحقق | رابط الدليل المحمي | المراجع |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| `SRC-YYYY-001` | `CONTRACT-REF` | اسم قانوني | مثال: قنوات أو VOD محددة | مثال: الجزائر فقط | Android / Web / أجهزة TV | نعم أو لا صراحة | حسب العقد | YYYY-MM-DD | YYYY-MM-DD | بانتظار أو موثق أو منتهي | معرف DMS داخلي | الاسم والتاريخ |

## قواعد القبول قبل تفعيل المصدر للمشاهدين

| شرط | الدليل المطلوب | نتيجة عدم وجوده |
|---|---|---|
| هوية الطرف المتعاقد | عقد أو فاتورة قانونية ووسيلة تحقق | يبقى المصدر معطلاً أو مقيداً للإدارة |
| حق التوزيع في التطبيق | نص صريح يذكر التطبيق أو OTT أو IPTV أو البث المناسب | لا يفترض الحق من شراء اشتراك فقط |
| الإقليم والجمهور | بند إقليمي واضح وقواعد منع الوصول عند الحاجة | لا يفتح المصدر عالمياً افتراضياً |
| إعادة البيع | بند صريح، وعدد المستفيدين أو النموذج التجاري | لا يباع للمستخدمين النهائيين قبل التحقق |
| تاريخ الانتهاء والتجديد | تاريخ قابل للتتبع وتنبيه قبل الانتهاء | يحدد المصدر على أنه معرض للانتهاء |
| معالجة الشكاوى | جهة اتصال ومسار إزالة أو تعليق | توثق الحادثة ويعطل المحتوى عند الحاجة |

## دورة المراجعة

يراجع مسؤول الامتثال كل مصدر مرة عند إدخاله، ثم قبل 60 و30 و7 أيام من تاريخ الانتهاء. لا يمسح سجل المصدر المنتهي؛ يتحول إلى حالة **منتهي** أو **معلق** وتحفظ الأدلة وتاريخ القرار. تُظهر واجهة المشاهد فقط القنوات المصرح بها، بينما تبقى provenance وقرار الامتثال وسجل المراجعة داخل الإدارة المخولة.
