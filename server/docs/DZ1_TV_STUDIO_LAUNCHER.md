# مدخل DZ1 TV Studio من لوحة DZ HOOF

## الهدف

يوفر هذا التغيير مدخلاً مريحاً للمشرف داخل قائمة إدارة DZ HOOF باسم **DZ1 TV Studio**. يفتح المدخل لوحة DZ1 TV في نافذة مستقلة، ولا يستدعي أي API أو قاعدة بيانات أو جلسة تابعة لـ DZ1 TV من داخل DZ HOOF.

> المدخل هو رابط تنقل للمشرف فقط، وليس تكاملاً للكتالوج أو الهوية أو الصلاحيات بين المنتجين.

## التكوين

يبقى المدخل مخفياً افتراضياً. لإظهاره، اضبط متغير البناء التالي في بيئة واجهة DZ HOOF فقط بعد أن تصبح لوحة DZ1 TV متاحة على عنوان HTTPS مستقل:

```bash
NEXT_PUBLIC_DZ1_TV_STUDIO_URL=https://studio.your-dz1-tv-domain.example/admin/
```

يقبل المكون عناوين `https://` فقط. العنوان غير الموجود أو غير الآمن يخفي المدخل ولا يغير سلوك لوحة DZ HOOF.

| الخاصية | السلوك |
|---|---|
| الظهور | يظهر للمشرف فقط داخل قسم مستقل في الشريط الجانبي |
| الانتقال | يفتح في علامة تبويب جديدة |
| حماية النافذة | يضيف `noopener noreferrer` لمنع وصول الصفحة الخارجية إلى نافذة DZ HOOF |
| المصادقة | لا يعيد استعمال cookie أو رمز DZ HOOF؛ يسجل مالك DZ1 TV دخوله بشكل مستقل |
| البيانات | لا يقرأ أو يكتب قنوات أو مصادر أو قوائم تشغيل DZ HOOF |

## قيود النشر

لا تضف هذا المتغير إلى `/etc/dzhoot/.env.production` ولا تشغّل نشر DZ HOOF قبل توفر عنوان DZ1 TV المستقل، والتحقق من TLS، وتشغيل لوحة DZ1 TV وقاعدة بياناتها المعزولة. لا تستخدم `iptv.ld-11.net` كوجهة للمدخل ولا تشير إلى نطاقات تجريبية أو داخلية.

يتطلب تطبيق التغيير على DZ HOOF الحي موافقة صريحة منفصلة، لأن واجهة DZ HOOF تعمل حالياً في الإنتاج. يبقى مصدر DZ1 TV وإعداده وبياناته وتشغيله مسؤوليات منفصلة.
