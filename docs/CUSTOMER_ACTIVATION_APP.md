# DZ HOOF — تطبيق العميل بكود التفعيل

## الهدف

تم تحويل تجربة البداية في تطبيق Android وAndroid TV من شاشة الاقتران الإدارية التي تعرض رابط الخادم وPIN إلى تجربة عميل نهائية. عند التثبيت، يرى العميل شاشة عربية تطلب **كود التفعيل** فقط؛ وبعد قبول الكود تُنشأ جلسة عميل، يُسجّل الجهاز ضمن حد الخطة، ويُفتح التطبيق على القنوات.

## التدفق الجديد

1. يثبت العميل ملف APK.
2. تظهر شاشة «مرحبًا بك في DZ HOOF».
3. يدخل كودًا بصيغة `DZHF-XXXX-XXXX-XXXX`.
4. يرسل التطبيق الكود مع معرف الجهاز إلى `POST /api/v1/activation/client-redeem`.
5. يتحقق الخادم من الكود والخطة وحالة الكود وحد الأجهزة.
6. في أول استخدام، يُنشأ حساب عميل داخلي غير تفاعلي، ويُنشأ اشتراكه وجهازه وجلسة طويلة العمر.
7. يحفظ التطبيق `sessionId` في التخزين الآمن، ويحفظ اعتماد قائمة القنوات، ثم ينتقل إلى Home.
8. عند تثبيت جهاز إضافي باستخدام الكود نفسه، يُعاد استخدام حساب العميل وتُطبّق حدود الخطة.

## الأمان والسلوك التجاري

المسار العام محدود المحاولات بحسب عنوان IP ومعرف الجهاز. لا يُعاد نص كود التفعيل من الخادم، ولا تُحفظ الجلسة في SharedPreferences العادية. الكود المستعمل يمكنه تسجيل أجهزة إضافية فقط ضمن `maxDevices` للخطة، ويمكن للإدارة حذف الأجهزة أو تعطيل حساب العميل.

يستخدم العميل اعتماد قائمة القنوات الصادر عن الخادم مع `X-TV-Code`، ويضيف `X-Session-Id` لمسارات الاشتراك والحساب. يجب في الإنتاج تشغيل HTTPS وتفعيل `SUBSCRIPTION_REQUIRED=true`، وعدم استخدام قاعدة MongoDB المؤقتة أو حسابات الاختبار.

## التحقق المحلي

نجح `assembleDebug` بعد إضافة الشاشة الجديدة وعقد Retrofit وbootstrap. كما نجح اختبار HTTP فعلي: إنشاء خطة مدتها 30 يومًا، توليد كود تجريبي، ثم استدعاء `client-redeem`، وكانت النتيجة اشتراك `ACTIVE` وجهازًا مسجلًا وجلسة عميل.

| العنصر | النتيجة |
|---|---|
| شاشة العميل العربية | مضافة |
| Android/Android TV build | `assembleDebug` ناجح |
| Backend typecheck | ناجح |
| Backend lint | ناجح مع تحذيرات موجودة مسبقًا فقط |
| client-redeem E2E | ناجح محليًا |
| Android unit tests | ما زالت تحتوي أخطاء قديمة غير مرتبطة مباشرة بالتدفق الجديد في عدة ViewModels وimports Mockito |

## ملاحظات الإصدار

النسخة الحالية **Debug** للتجربة وليست Release موقعة للنشر التجاري. قبل توزيعها على الزبائن يجب إنشاء إعداد إنتاجي بعنوان VPS دائم، وتفعيل HTTPS، وضبط مصدر القنوات المصرح به، وإنشاء Release signing key خارج GitHub، ثم اختبار استرجاع الجلسة والتشغيل على هاتف وAndroid TV فعليين.
