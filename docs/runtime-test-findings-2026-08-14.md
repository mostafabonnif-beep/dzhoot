# نتائج الاختبار المرحلي — 2026-08-14

- MongoDB وRedis وMailHog تعمل في حاويات مستقلة.
- Backend `/health` أعاد status=ok مع MongoDB وRedis متصلين.
- Frontend `/login` أعاد HTTP 200.
- محاولة الدخول الأولى كشفت خطأ إعداد مؤقتًا: الواجهة كانت تستعمل `/api/v1` في NEXT_PUBLIC_API_URL بينما عميل Axios يضيف `/api/v1`، فنتج `/api/v1/api/v1/auth/login` و404.
- تم إصلاح إعداد التشغيل بإعادة تشغيل Frontend مع عنوان Backend العام دون `/api/v1`.
- تسجيل الدخول الثاني نجح، وطلبات `/api/v1/auth/me` و`/api/v1/config/defaults` وواجهات الإحصائيات أعادت 200.
- لوحة الإدارة ظهرت بالعربية مع قائمة الصفحات والإحصائيات وسجل النشاط.
- بيانات الدخول التطويرية لم تُحفظ في المستودع، وكلمة المرور بقيت محلية فقط ولم تُضمّن في التقرير.
