# DZ HOOF Client 2.0 — تحديث المرحلة الثانية

**التاريخ:** 2026-08-27  
**الحالة:** مكتملة برمجياً ومتحقق منها محلياً؛ لا يوجد نشر إنتاجي

## نطاق العمل

ركزت هذه المرحلة على جعل تجربة الهاتف وAndroid TV مختلفة وظيفياً، وليس فقط تغيير الألوان أو إعادة ترتيب العناصر. تمت مراجعة مسارات الكتالوج والتصنيفات والتفاصيل، مع الحفاظ على واجهات Backend وبيانات الحسابات.

## التغييرات

| المجال | التغيير | الفائدة |
|---|---|---|
| لوحة الرئيسية | تضمين callbacks التنقل ضمن مفاتيح `remember` | منع استدعاء وجهة قديمة بعد إعادة إنشاء NavHost أو تغير حالة الشاشة |
| الكتالوج | أحجام ملصقات متجاوبة حسب عرض الشاشة | كثافة أفضل على الهاتف وبطاقات أكبر وأسهل للريموت على التلفاز |
| تفاصيل الفيلم | تحويل التخطيط إلى عمودي على الهاتف وجانبي على التلفاز | منع ضغط الصورة والنص وخروج المعلومات من شاشة الهاتف |
| تفاصيل المسلسل | جعل صورة الحلقة والنص متجاوبين مع الهاتف والتلفاز | تحسين قراءة الحلقات والتنقل بينها باللمس أو D-pad |
| التصنيفات | إلغاء إخفاء الفئات التي تحتوي أقل من ثلاث قنوات | كل قناة صحيحة تبقى قابلة للوصول ولا تضيع بسبب فلتر شكلي |
| اللغة | تصحيح عداد المفرد والجمع في بطاقة التصنيف | عرض «1 قناة» و«2 قنوات» بصورة صحيحة |
| البحث | منع تكرار القناة بين نتائج الكتالوج والفهرس المحلي | عداد نتائج أدق وتجربة اكتشاف بدون بطاقات مكررة |

## حدود التحقق

التحقق الحالي آلي ومحلي، ولا يثبت بعد تجربة D-pad على جهاز Android TV فعلي أو تشغيل مصادر IPTV الحية. يجب إجراء اختبار جهاز/محاكي قبل بناء `officialRelease`، خصوصاً لمسارات التركيز وفتح التفاصيل والعودة منها.

## القرار التالي

بعد تثبيت تغييرات المرحلة الثانية، يبدأ اختبار التوافق النهائي على شاشات الهاتف والتلفاز، ثم إعداد APK مراجعة داخلي جديد. لا يُستخدم أي APK debug في التحديث العام، ولا يتم رفع إصدار إلى خادم التنزيل قبل التحقق من توقيع الإنتاج ونسخة API التحديث.
