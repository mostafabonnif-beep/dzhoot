## شروط إصدار APK للزبائن

لا يجوز توزيع `officialDebug` على الزبائن. يجب أولاً توفير keystore الإنتاجي نفسه المستخدم في `1.0.17`، مع أسراره عبر GitHub Actions Secrets فقط، ثم تشغيل Workflow الرسمي لبناء `officialRelease`.

بعد البناء يجب حفظ APK وملف SHA-256، والتحقق من التوقيع v2 وشهادة التوقيع و`packageName` و`versionName` و`versionCode`. يجب تجربة تثبيت APK فوق `1.0.17` على جهاز فعلي أو محاكي، ثم فتح التطبيق والتحقق من بقاء الحساب وقائمة القنوات والمفضلة والإعدادات.
