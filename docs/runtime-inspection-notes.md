# Runtime inspection notes — 2026-08-15

تم تشغيل الخادم المؤقت والتحقق من واجهة لوحة الإدارة عبر الرابط المؤقت. صفحة `/login` تحمل بنجاح بعنوان DZ HOOF IPTV، وتعرض واجهة عربية RTL مع عناصر اسم المستخدم وكلمة المرور وزر تسجيل الدخول وروابط OAuth. لا يظهر خطأ تحميل أو صفحة فارغة في الفحص البصري الأولي.

الخدمات المحلية المرصودة: Backend على المنفذ 8009، Frontend على المنفذ 3001، وMailHog على 8025. سيتم استكمال الفحص عبر HTTP وواجهات API مع عدم طباعة كلمات المرور أو الجلسات أو مصادر المحتوى.

بعد إعادة تشغيل Backend، أعاد Frontend HTML ناجحًا عبر الرابط العام، لكن لقطة المتصفح المؤقتة ظهرت بدون تنسيق CSS رغم أن صفحة الدخول كانت منسقة في الفحص السابق. سيُتحقق من ملفات CSS وحالة Next dev server عبر HTTP مباشرة؛ لا تُعد هذه الملاحظة عطلًا مثبتًا في نسخة الإنتاج قبل مقارنة استجابات الأصول.

تبين أن ظهور الصفحة دون CSS كان سببه تشغيل `npm run build` بالتزامن مع Next.js dev، ما ترك manifest غير متسقًا وأعاد `/_next/static/css/app/layout.css` بحالة 404. أُعيد تشغيل Frontend بعد حذف `.next` وإعادة توليد cache؛ أصبح `/login` يعيد 200، وأصل CSS يعيد 200 مع `text/css` محليًا، ثم عادت اللقطة العامة إلى التصميم العربي الكامل.
