# خارطة تطوير DZ HOOF IPTV نحو منتج قابل للمنافسة

## الملخص التنفيذي

يمتلك DZ HOOF الآن نواة جيدة: تفعيل العميل بكود، خطط واشتراكات، تحديد محتوى حسب الخطة، لوحة إدارة، Secure Playback، تطبيق Android، ودعم RTL عربي. لكنه لا يزال في مرحلة **Beta تقنية** وليس منتجًا تجاريًا مكتملًا؛ لأن المحتوى الحقيقي، جودة البث المقاسة، الاستضافة الدائمة، تجربة Android TV، ونسخة Release الموقعة لم تكتمل.

المنافسة لا تُحسم بعدد الميزات فقط. المنصة القوية تحتاج إلى أربعة عناصر متوازنة: الاعتمادية، قابلية التوسع، مرونة تحقيق الدخل، وتجربة استخدام واضحة [1]. كما أن المنصات الحديثة تتجه إلى دعم الأجهزة المتعددة، Live وVOD وSeries وEPG وCatch-up، حماية التشغيل عبر tokens، وتحسين الجودة حسب ظروف الشبكة [2].

## التموضع المقترح

يجب تقديم DZ HOOF على أنه **منصة اشتراك ترفيهية عربية منظمة** تمنح العميل وصولًا بسيطًا عبر كود تفعيل، وتدير المحتوى والخطط مركزيًا. لا ينبغي تسويقه على أنه جامع مصادر مجهولة أو أداة لتجاوز حقوق البث. الميزة التجارية الأساسية هي: تجربة عربية نظيفة، تفعيل سريع، محتوى مرخص ومنظم، دعم واضح، وتشغيل مستقر.

## الأولويات قبل VPS

### P0 — يجب إنجازه أولًا

أولًا، يجب توفير مصدر محتوى قانوني ومرخص، ثم بناء دورة كاملة في لوحة الإدارة: إضافة المصدر، اختبار الاتصال، المزامنة، تنظيف البيانات الوصفية، تصنيف القنوات، تحديد المحتوى لكل خطة، ثم تشغيل قناة حقيقية من الهاتف. لا يمكن تقييم المنتج أو تسويقه قبل أن تظهر بيانات فعلية ويعمل البث باستقرار.

ثانيًا، يجب اختبار Secure Playback بمصدر حقيقي. يجب ألا يرى العميل أو المتصفح رابط upstream، ويجب أن تكون رموز التشغيل قصيرة العمر ومربوطة بالمستخدم أو الجهاز والخطة، مع رفض الرمز بعد انتهائه. كما يجب اختبار السلوك عند انقطاع Redis أو فشل المصدر بدل السماح بتراجع أمني.

ثالثًا، يجب تحسين حالات التشغيل: تحميل أولي سريع، retry مضبوط، رسالة خطأ عربية مفهومة، timeout واضح، زر إعادة المحاولة، ومؤشر يميز بين عدم وجود محتوى، انتهاء الاشتراك، ومشكلة الشبكة.

### P1 — ما يجعل المنتج منافسًا فعليًا

يحتاج العميل إلى بحث سريع، فلاتر حسب النوع واللغة، مفضلة، متابعة المشاهدة، آخر القنوات، سجل المشاهدة، ومحتوى مقترح. هذه الميزات أهم من إضافة صفحات كثيرة لا يستخدمها العميل.

يجب إضافة EPG منظم للقنوات، وصف البرنامج الحالي والقادم، وتسجيل Catch-up عندما تسمح الحقوق والمصدر. كما يجب توفير مشغل Live وVOD موحد مع اختيار الجودة تلقائيًا، واستئناف VOD من آخر موضع.

يجب تحسين Android TV أو إنشاء مسار TV واضح: دعم D-pad، التركيز المرئي، زر الرجوع، أحجام الشاشات، القراءة من مسافة، الوضع الأفقي، واختبار تشغيل القنوات على جهاز TV أو محاكي فعلي.

### P1 — البنية الإنتاجية

قبل البيع يجب نشر Backend وFrontend على VPS دائم بنطاق وHTTPS، مع MongoDB وRedis محميين، أسرار إنتاج جديدة، CORS مقيد، healthchecks، مراقبة، نسخ احتياطي إلى مكان منفصل، وRestore Drill. يجب إضافة CDN أو استراتيجية توزيع مناسبة إذا تجاوز عدد المشاهدين قدرة الخادم.

يجب بناء APK Release موقّع، تخزين keystore في GitHub Secrets أو مدير أسرار، اختبار التحديث من نسخة سابقة، وتثبيت `google-services.json` خارج Git. نسخة Debug الحالية للاختبار وليست منتجًا تجاريًا.

### P2 — الاحتفاظ بالعملاء والنمو

بعد استقرار الأساس، يجب إضافة إشعارات FCM حقيقية، تنبيهات انتهاء الاشتراك، إشعار المحتوى الجديد، مركز دعم، قياس وقت بدء التشغيل ونسبة التقطيع والأخطاء، وتقارير استخدام للوحة الإدارة. التحليلات يجب أن تكون privacy-aware ولا تجمع بيانات أكثر من اللازم.

يجب إضافة كوبونات، تمديد اشتراك، سجل عمليات الأكواد، وربما الدفع الإلكتروني في مرحلة لاحقة فقط. نظام الموزعين يبقى مؤجلًا إلى V2 حتى لا يشتت الفريق عن جودة النسخة الأولى.

## ما يميز DZ HOOF عن المنافسين

ينبغي التركيز على ثلاث مزايا قابلة للإثبات بدل ادعاءات عامة. الأولى هي **تجربة عربية حقيقية** وليست ترجمة جزئية. الثانية هي **تفعيل سريع بلا إعداد تقني**؛ العميل يدخل الكود فقط. الثالثة هي **محتوى منظم وخدمة دعم موثوقة** مع إظهار حالة الاشتراك بوضوح.

يمكن إضافة هوية مرئية متماسكة، صفحة تعريف، مركز مساعدة، رسائل بريد أو إشعارات انتهاء الاشتراك، وتجربة دعم عبر WhatsApp أو نموذج داخل التطبيق، بشرط حماية بيانات العملاء وعدم نشر بيانات الدخول.

## معايير عدم الإعلان عن الجاهزية قبل تحققها

لا يُعلن المنتج جاهزًا للسوق قبل تحقق الشروط التالية: وجود مصدر محتوى قانوني فعلي، نجاح تشغيل Live وVOD وSeries، اختبار انتهاء الاشتراك وحد الأجهزة، عدم كشف روابط المصدر، تشغيل HTTPS دائم، نجاح النسخ الاحتياطي والاستعادة، APK Release موقّع، تجربة Android TV إن كان ضمن السوق، وتوفر سياسة خصوصية وشروط استخدام ودعم واضح.
