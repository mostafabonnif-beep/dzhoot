## 3. الأعطال المكتشفة والمعالجة

### F1 — كاش بناء قديم يكسر `npm run build` ✅ أُصلح
- **السبب**: ملف `tsconfig.tsbuildinfo` قديم (مُصدَّر من بيئة سابقة) يخدع `tsc` فيتخطى الإخراج (`dist/` غير موجود)، ثم يفشل `cp -R src/templates dist/templates`.
- **المعالجة**: حذف الملف + إضافة `*.tsbuildinfo` إلى `.gitignore` (الجذر و backend).

### F2 — استيراد Xtream محجوب كليًا عند حجب IP البث (بيضة ودجاجة) ✅ أُصلح — **الأهم لك**
- **السبب**: المزامنة مشروطة بـ `verificationStatus === 'verified'` الذي يتطلب **بثًا حيًا قابلًا للتشغيل من IP الخادم**. عند حجب البانل لـ IP الخادم (456/401 — حالة Upstream لديك)، يفشل التحقق → **يمنع استيراد الكتالوج أصلًا** رغم أن واجهة `player_api.php` تعمل.
- **المعالجة**:
  - `services/xtream-service.ts`: `syncXtreamSource(id, { allowCatalogOnly: true })` — يسمح باستيراد الكتالوج عندما يكون التحقق `degraded` (API سليمة، بث محجوب)، ويرفض فقط إذا كان `blocked`، ويسجل `catalogOnlyImportedAt`.
  - `models/XtreamSource.ts`: حقل جديد `catalogOnlyImportedAt`.
  - `routes/admin-xtream-sources.js`: مسار جديد `POST /:id/import-catalog` (أدمن فقط) + سجل تدقيق `XTREAM_SOURCE_CATALOG_IMPORT`.
  - **الأمان محفوظ**: المصدر يبقى `Inactive` وغير قابل للتفعيل حتى يجتاز تحقق البث الحقيقي؛ البروكسي ما زال يرفض/يفشل بث المصادر غير الموثقة.

### F3 — حقل `stream_icon`/`backdrop_path` يأتي مصفوفة من البانل فيكسر الاستيراد ✅ أُصلح
- **السبب**: بعض أفلام Xtream ترجع `stream_icon` و`backdrop_path` كمصفوفة `["url"]`، والحقل في Mongoose من نوع String → `Cast to string failed` عند الفيلم ~66,670، فينهار الاستيراد كاملًا بعد ساعات.
- **المعالجة**: دوال `iconUrl()` و `toStringOrEmpty()` في `xtream-service.ts` تطبَّق على `channelImg`/`poster`/`backdrop`/`description` (3 مواضع).

### F4 — خدمة EPG تفشل مع iptv-epg.org (302 redirect) ✅ أُصلح
- **السبب**: `maxRedirects: 0` في طلب axios — وiptv-epg.org يعيد توجيه 302 → فشل جلب كل مصادر EPG (ضجيج متكرر في السجل).
- **المعالجة**: متابعة redirects يدويًا (حتى 4 قفزات) مع **إعادة فحص SSRF لكل قفزة** (لا يمكن للتحويل الهروب إلى عنوان داخلي) + تحديد gzip على الرابط النهائي.

### F5 — توقف الخادم صامتًا أثناء العمل (استقرار) ⚠️ يحتاج إجراء خارجي
- **السبب**: العملية ماتت دون رسالة خطأ (مرجّح ضغط ذاكرة أثناء استيراد iptv-org + بناء الواجهة معًا على 3.8GB).
- **الإجراء**: في الإنتاج استخدم مراقب عمليات (systemd `Restart=always` أو PM2) — Docker Compose الإنتاجي لديك يعالجها جزئيًا.

### F6 — إعدادات تشغيل محلية (توثيق) ⚠️
- Rewrites الواجهة (`localhost:8009`) تُثبَّت **وقت البناء** وليس وقت التشغيل — `NEXT_PUBLIC_API_URL` يجب أن تمر وقت `next build` (في إنتاج Caddy يتولى التوجيه فلا مشكلة).
- `GET /app/version` يعتمد على GitHub API كاحتياطي — يفشل بدون إنترنت/Releases؛ الأفضل الاعتماد على جدول `AppVersion` المحلي أولًا.
